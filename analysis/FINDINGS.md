# Marni リテール H1(上期)売上分析 — FINDINGS

対象範囲: **コレクション26ドア（Retail Store + Retail Concession）、円建て、2025年H1(1-6月) vs 2026年H1(1-6月)**。
MARNI MARKET系・Café・POP UP・Outlet・Online・卸は含まない（詳細は「4. データの限界」参照）。
数値はすべて `data/` 配下のCSV（`analysis/analyze.py` で集計・`analysis/output/` に出力）から算出した実測値。
比較軸は対前年（vsLY）のみ（予算データが存在しないため対計画は算出していない）。

## 1. 結論（経営が持ち帰るべきメッセージ）

- H1累計Net売上は前年比+0.3%（+7.0百万円、2,215.9→2,223.0百万円）とほぼ横ばいだが、客数(TR)は-10.8%と大幅減少しており、客単価(ATV)+12.4%で穴埋めした構造。TR要因は約-239百万円のマイナス、ATV要因が約+246百万円のプラスでこれを相殺している。
- この横ばいは2025年5月新規オープンの渋谷パルコ1F（+347.9%）を含んだ数字であり、**既存25ドアだけで見ると売上-1.4%・客数-12.9%で実質減収基調**。
- 収益の質も悪化: プロパー(FP)売上が-114百万円(-6.0%)減少し、セール(MD)売上+121百万円(+36.3%)がこれを埋めた。値引率自体は横ばい(39.7%)だが、MD構成比が15.0%→20.4%(+5.4pt)に拡大しており、値引き販売への依存度が高まっている。
- 顧客基盤は毀損が継続: 2025年購入者のうち30.51億円相当の売上が2026H1に失われ(Lost)、新規顧客のTR減少(-1,369件、金額影響概算-1.67億円)が既存顧客の増加(+97件、+0.18億円)を大きく上回る。加えて50万円以上の上位顧客のリテンションは61.2%→58.2%と悪化しており、全体指標の改善の裏で最重要顧客層の離反が進んでいる。
- バッグ事業の縮小（特にShopping_Bag -71.3百万円、Shoulder_Bag -18.5百万円）とRTWへの構造転換（44.8%→49.8%）が進行中。ただしHandbagsは+20.5百万円と増加しており、バッグ全体が一律に不振なのではなく特定の商品タイプに問題が集中している。

### 2-4. 収益の質の劣化（FP/MD）

| 項目 | 差額 |
|---|---|
| FP(プロパー)売上 差額 | **-114.0百万円**（-6.0%、1,884→1,770百万円） |
| MD(セール)売上 差額 | **+121.0百万円**（+36.3%、332→453百万円） |
| 合計差額 | +7.0百万円（= Net売上前年差と一致） |

MD構成比15.0%→20.4%(+5.4pt)。一方で平均値引率は39.7%で横ばいのため、「値引き幅を広げた」のではなく「値引き販売の点数構成を増やした」ことで売上を維持した可能性が高い。FP売上の減少額(-114百万円)をMD売上の増加額(+121百万円)がほぼ相殺しており、**「売上を維持できたのはセール依存が進んだから」という見立ては金額ベースで支持される**。

### 2-5. 顧客基盤の毀損

- **Lost顧客（2025年通年購入・2026H1未再購入）が失った2025年売上は合計 30.51億円**（10-30万円層14.55億円・Lost率93%／10万円未満8.99億円・Lost率97%／30-50万円3.51億円・Lost率76%／50-100万円2.29億円・Lost率53%／100万円以上1.17億円・Lost率22%）。低単価層ほどLost率が高いが、金額インパクトは10-30万円層が最大。
- 新規/既存の内訳: 新規TR -1,369件、既存TR +97件。2026年ATV（新規121,894円・既存183,850円）で金額換算すると、**新規顧客の客数減少による影響は概算-1.67億円、既存顧客の増加による影響は概算+0.18億円**で、新規顧客の減少が既存顧客の増加の約9倍のマイナスインパクト。「新規顧客の減少が主因」と金額ベースで裏付けられる（この概算はATV一定を仮定した粗い推計であり、厳密な要因分解ではない点に留意）。
- 支出階層別の二極化: 300万円以上+44.0%、100-300万円+30.0%、50-100万円+11.7%、30-50万円+14.5%と上位4階層は増加している一方、10-30万円-0.4%、10万円未満-12.5%と下位2階層は減少・横ばい。ただし2026年売上構成比は上位4階層合計で38.7%、下位2階層合計で61.1%であり、**金額の絶対規模としては依然として下位階層(10-30万円・10万円未満)が売上の6割強を占める**ため、上位層の伸びだけでは下位層の縮小を金額的に補いきれていない。
- 全体の再購入率は6.6%→7.7%、売上加重リテンションは22.2%→25.6%と改善している一方、**50万円以上顧客のリテンションは61.2%→58.2%（-3.0pt）と悪化**している。全体指標の改善に埋もれて最重要顧客層の離反が進んでいる可能性があり、見落としてはならない。

## 3. 経営として意思決定すべき論点（3〜5個）

**論点1: 既存店の客数減少（既存25ドアで-12.9%）に歯止めがかかっていない**
- 事実: 全社+0.3%は渋谷パルコ1F（新規オープン、+347.9%）を含む数字で、既存25ドアだけでは売上-1.4%・TR-12.9%。
- 示唆: 新規出店がなければ実質減収。既存店の集客力低下が構造的な問題として続いている。
- 意思決定事項: 新規出店の成果と既存店の実力を切り分けて経営会議に報告する運用へ切り替えるか。既存店の客数減少に対する集客投資（Traffic不在のためデータ計測から着手する必要あり）の是非。

**論点2: MD(セール)依存の拡大が実質的に減収を隠している**
- 事実: FP売上-114百万円をMD売上+121百万円がほぼ相殺（合計+7.0百万円）。MD構成比15.0%→20.4%(+5.4pt)、値引率は横ばい39.7%。
- 示唆: 粗利率を維持する値引き対応ではなく、セール販売の点数構成拡大で売上を下支えしている。この構造が続けば収益性は徐々に悪化する可能性がある。
- 意思決定事項: MD構成比に上限（ガードレール）を設けるか、FP強化（新規顧客獲得・接客品質）への投資配分を見直すか。

**論点3: 新規顧客の減少が顧客基盤毀損の主因（既存顧客の増加では補えない規模）**
- 事実: 新規TR-1,369件（金額影響概算-1.67億円）が既存TR+97件（+0.18億円）を大きく上回る。Lost顧客（2025年購入・2026H1未再購入）は合計30.51億円相当の売上を失った。
- 示唆: 既存顧客のリテンション改善だけでは新規流入の細りを補いきれない規模の目減りが起きている。
- 意思決定事項: 新規顧客獲得（集客・認知・アウトリーチ）への投資を、既存顧客のClienteling強化と並行してどう配分するか。

**論点4: 全体指標の改善の裏で、最重要顧客層（50万円以上）の離反が進んでいる**
- 事実: 全体の売上加重リテンションは22.2%→25.6%(+3.4pt)と改善する一方、50万円以上顧客のリテンションは61.2%→58.2%(-3.0pt)と悪化。
- 示唆: 全体指標だけを見ると顧客基盤は改善しているように見えるが、内訳を見ると最も収益貢献度の高い顧客層で離反が進んでいる。
- 意思決定事項: 上位顧客向けの個別フォロー（外商・Clienteling）体制の強化と、離反原因の追加調査（接客体制・在庫・招待施策等）に着手するか。

**論点5: バッグ事業の不振はShopping_Bag/Shoulder_Bagに集中しており、カテゴリ一律の縮小ではない**
- 事実: Shopping_Bag-71.3百万円・Shoulder_Bag-18.5百万円が減少を牽引する一方、Handbagsは+20.5百万円と増加。Footwearも構成比は小さいがNet-33.2%・数量-47.9%と悪化幅が全カテゴリ最大。
- 示唆: バッグ事業全体を一律に縮小するのではなく、商品タイプ別のテコ入れ余地がある。Footwearも規模は小さいが放置すると構成比がさらに縮小する可能性がある。
- 意思決定事項: バッグのMD計画（仕入れ・VP）を商品タイプ別に見直すか、Shopping_Bag/Shoulder_Bagの価格・デザイン・VMD施策を検討するか。

## 4. データの限界（正直な列挙）

- **予算（Budget）データなし**: 対計画の達成率・良否判断ができない。`store_clienteling_kpi_2025.csv`にBDG(EUR)列が存在するが、対象範囲（29拠点+Outlet3）・通貨（EUR）が26ドア・円建ての他CSVと異なるため、対計画分析には使用していない。
- **Traffic（入店客数）・CVRデータなし**: 本分析のTR(客数)は購買客数（トランザクション数）であり、来店したが購入しなかった客数は不明。客数減少が「集客の問題」か「転換率の問題」かを切り分けられない。`202603_Foot Flow.xlsx`はセンサー設置状況のみで実測値なし。
- **対象は「コレクション26ドア」（Retail Store + Retail Concession）に限定**: MARNI MARKET系（上期¥162M）・Café・POP UP・Outlet・Online・卸(OTHER)は含まない。本資料の数字を「全社売上」と呼ぶことはできない。
- **DSR（日次）相当のデータなし**: 月次より細かい粒度（週次・日次）のデータは今回のスコープでは取得できていない。月内のどのタイミングで売上が動いたかは不明。
