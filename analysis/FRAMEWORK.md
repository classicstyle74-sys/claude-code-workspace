# 売上分析フレームワーク（Marni リテール）

実データ到着前の準備フェーズとして、分析の設計図を定義する。実データが `data/` に届き次第、
このフレームワークに沿って `analyze.py` を実行し、スライド化する。

## 1. 売上分解式

```
Revenue = Traffic × CVR × ATV
ATV     = UPT × AUR
```

| 指標 | 定義 | 悪化/改善の判定ルール |
|---|---|---|
| Traffic | 来店客数（入店数） | 前年比・計画比が -X%以上のマイナスで「悪化」。閾値の目安: ±5%未満=横ばい, -5%〜-15%=要注意, -15%超=重大 |
| CVR | 購買率（Transaction / Traffic） | 同上の閾値をCVRのpt差（前年比/計画比の差分pt）で判定。目安: ±1pt未満=横ばい, -1〜-3pt=要注意, -3pt超=重大 |
| ATV | 客単価（Sales / Transaction） | 前年比・計画比のマイナス幅で判定（Traffic/CVRと同様の閾値） |
| UPT | 買上個数（Units / Transaction） | ATV変動のうち「点数要因」を特定するための補助指標。UPT低下はまとめ買い減少・関連購買の弱さを示唆 |
| AUR | 平均単価（Sales / Units） | ATV変動のうち「単価要因」を特定するための補助指標。AUR低下は値引き拡大・低単価品構成比増を示唆 |

**寄与度分解の考え方**：Revenue前年差を Traffic要因 / CVR要因 / ATV要因（さらにUPT要因・AUR要因）に分解し、
どの要素が売上変動に最も寄与しているかを特定する（対数差分近似 or 順次代入法のいずれかで実装）。

## 2. 分析軸

1. **期間推移** — 日次/週次/月次のトレンド、直近4〜13週の移動平均
2. **店舗別** — 全店舗を対象にKPIをランキング化（Revenue規模別・前年比別）
3. **百貨店 vs 路面店** — チャネル種別ごとのKPI比較（構造的な差異の把握）
4. **カテゴリ別** — 商品カテゴリ別のRevenue構成比・前年比・利益率（データがあれば）
5. **顧客区分（New / Loyal / Lost）** — 客数構成・売上構成の変化、Lost顧客の離脱要因仮説
6. **前年比・計画比** — 全軸に対して共通で付与する比較レイヤー

## 3. 要注意店舗の機械的抽出ルール

以下のスコアリングを店舗ごとに算出し、上位N店舗（またはスコア閾値超）を「要注意店舗」としてフラグする。

```
risk_score = w1 * max(0, -YoY_Revenue_pct)
           + w2 * max(0, -vsPlan_Revenue_pct)
           + w3 * max(0, -YoY_Traffic_pct)
           + w4 * max(0, -YoY_CVR_pt)
           + w5 * max(0, -YoY_ATV_pct)
           + w6 * Lost顧客比率の増加pt
```

- 初期重み案: w1=0.3, w2=0.3, w3=0.15, w4=0.1, w5=0.1, w6=0.05（データ到着後に調整）
- 追加条件: Revenue規模が一定以上（ロングテールの小規模店を上位に出さないための下限フィルタ）
- 出力: 店舗名、risk_score、主要因（Traffic/CVR/ATVのうちどれが最大寄与か）、前年比、計画比

## 4. スライド想定チャート一覧（10個）

| # | チャート | 形式 | 目的（何を言うため） |
|---|---|---|---|
| 1 | 全社Revenue推移（週次/月次、前年重ね） | 折れ線グラフ | 全体トレンドと季節性、前年からの乖離を示す |
| 2 | Revenue前年差のウォーターフォール（Traffic/CVR/ATV寄与度分解） | ウォーターフォールチャート | 何が売上変動を牽引したかを一目で示す |
| 3 | 店舗別Revenue×前年比 散布図 | 散布図（バブル=Revenue規模） | 規模と成長率のポジショニングを俯瞰 |
| 4 | 要注意店舗ランキング（risk_score上位10店） | 横棒グラフ | どの店舗に即対応が必要かを明示 |
| 5 | 百貨店 vs 路面店 KPI比較 | グループ棒グラフ（Traffic/CVR/ATV） | チャネル特性の違いを構造的に示す |
| 6 | カテゴリ別Revenue構成比（当年 vs 前年） | 積み上げ棒グラフ | 商品構成の変化を示す |
| 7 | 顧客区分別売上構成推移（New/Loyal/Lost） | 積み上げ面グラフ | 顧客基盤の健全性・Lost拡大の兆候を示す |
| 8 | Lost顧客率 前年比トレンド | 折れ線グラフ | 顧客離脱が進行中か改善中かを示す |
| 9 | 計画比達成率ヒートマップ（店舗×月） | ヒートマップ | 未達が特定の時期・店舗に集中していないか示す |
| 10 | ATV分解（UPT要因 vs AUR要因） | 二軸棒グラフ/ウォーターフォール | 客単価変動が「点数」か「単価」かを切り分ける |

## 5. 実装メモ

- 列名はソースにより変わる想定のため、`analyze.py` の `COLUMN_MAP` で正規化してから集計する。
- 前年比較には日付軸の週定義（ISO week等）を揃える必要がある。データ到着後に確認。
- 百貨店/路面店、New/Loyal/Lost の区分定義もデータ側のマスタに依存するため、到着後にマッピングを確定する。
