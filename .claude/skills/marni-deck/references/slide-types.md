# スライドタイプ仕様

`build_deck.py` に渡すスペック JSON の形式:

```json
{
  "slides": [
    { "type": "<タイプ名>", ...フィールド... }
  ]
}
```

全タイプ共通の任意フィールド:

- `notes` — スピーカーノート(文字列)

テキスト系フィールドは `\n` で段落を分けられる。`null` または省略で
テンプレートの元テキストが残るため、**表示されるフィールドは必ず指定する**こと
(プレースホルダー文言が残ってしまう)。

文字数の「目安」は半角換算。全角文字は約2倍の幅を取るため、日本語では
目安の半分程度と考える。

---

## cover — 表紙

赤背景 + MARNI ロゴ。デッキの先頭に使う。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` | ✓ | 表紙タイトル(中央下部)。**1 行は半角 24 字/全角 12 字まで、最大 2 行**(`\n` で明示的に改行)。3 行になるとフッターに重なる |

## toc — 目次

グレー背景。番号 / 項目名 / ページ番号の 3 列。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` | | ヘッダー(既定 "Table of Content") |
| `secnum` | | 左上の番号(既定 "0.0") |
| `items` | ✓ | 配列。各要素 `{"num": "1.0", "title": "...", "page": "04"}` |

最大 9 行。`title` は 1 行に収まるように(目安 45 字)。

## section_red — セクション区切り(赤)

赤一色 + 左上に「番号 + セクション名」。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` | ✓ | セクション名(目安 50 字) |
| `secnum` | ✓ | セクション番号(例 "1.0") |

## section_black — セクション区切り(黒)

黒一色 + キャメル色の見出し。フィールドは section_red と同じ。

## text_image — 本文 + 画像

グレー背景。左 1/3 に本文、右 2/3 に画像パネル。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` | ✓ | ページ見出し(目安 50 字) |
| `secnum` | ✓ | 左上の番号(例 "2.1") |
| `body` | ✓ | 本文(目安 700 字 / 日本語 350 字) |
| `image` | | 画像ファイルパス。省略時はその領域は空白(背景色)になる |

画像なしの純テキストページとしても使える。

## two_images — 画像 2 枚

グレー背景。大きな画像パネル 2 枚 + 下部キャプション。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` | ✓ | ページ見出し |
| `secnum` | ✓ | 左上の番号 |
| `images` | | パスの配列(最大 2)。`[左, 右]` |
| `caption` | | 中央下のキャプション(目安 40 字) |

## three_columns — 3 カラム比較

黒い帯(全体見出し + 列見出し 3 つ)+ 画像 3 枚 + 説明文 3 つ。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` | ✓ | ページ見出し |
| `secnum` | ✓ | 左上の番号 |
| `band_title` | ✓ | 黒帯上部の全体見出し(目安 60 字) |
| `columns` | ✓ | 配列(最大 3)。各要素 `{"subtitle": "...", "image": "パス", "body": "..."}` |

`body` は短く(目安 120 字 / 日本語 60 字)。列が 2 つの場合、3 列目の
`subtitle`/`body` に `""` を指定してプレースホルダー文言を消すこと。

## quote — 引用・キーメッセージ

黒背景 + キャメル色の大きな引用文。

| フィールド | 必須 | 説明 |
|---|---|---|
| `quote` | ✓ | 引用文(目安 220 字 / 日本語 110 字)。引用符も含めて書く |
| `label` | | 上部の小さなラベル(発言者など)。省略時は空になる |

## bullets — 箇条書き(拡張)

グレー背景。赤角マーカー + 見出し + 説明文。4 項目超は自動で 2 カラム。
画像のない文章コンテンツは `text_image` ではなくこれを使う。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` / `secnum` | ✓ | ページ見出しと番号 |
| `lead` | | 冒頭のリード文(目安 170 字 / 日本語 85 字) |
| `items` | ✓ | 配列(最大 8)。`{"head": "見出し", "text": "説明"}` または文字列 |
| `columns` | | 1 か 2。省略時は項目数で自動 |

`head` は目安 40 字、`text` は目安 170 字(日本語はその半分)。

## chart — チャート(拡張)

ブランド配色のネイティブ PowerPoint チャート(編集可能)。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` / `secnum` | ✓ | ページ見出しと番号 |
| `chart_type` | ✓ | `column` / `bar` / `line` / `pie` / `doughnut` |
| `categories` | ✓ | カテゴリ名の配列 |
| `series` | ✓ | `[{"name": "系列名", "values": [数値...]}]`。pie/doughnut は 1 系列のみ |
| `body` | | 左に置く解説文(目安 380 字)。あるとチャートは右 2/3 に配置 |
| `source` | | 下部の出典表記 |

系列色は赤→黒→キャメル→ライラック→ダークブラウンの順で自動適用。

## stats — KPI タイル(拡張)

大きな数値を色ブロックで見せる。2〜4 枚。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` / `secnum` | ✓ | ページ見出しと番号 |
| `lead` | | 冒頭のリード文 |
| `items` | ✓ | `[{"value": "+18%", "label": "売上成長率", "desc": "補足"}]` |

`value` は短く(7 字以内)。タイル色は赤→黒→キャメル→ダークブラウンの順。

## flow — プロセス図(拡張)

番号付き色ブロックの横並び。手順・ステップの表現に。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` / `secnum` | ✓ | ページ見出しと番号 |
| `steps` | ✓ | 配列(3〜5)。`{"head": "工程名", "text": "説明"}` |

## comparison — 2 案比較(拡張)

色帯ヘッダー + 白パネルの 2 カラム対比。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` / `secnum` | ✓ | ページ見出しと番号 |
| `left` / `right` | ✓ | `{"head": "A案", "items": ["...", ...], "color": "black|camel|red|brown|lilac"}` |

`items` は各 6 個まで、1 項目 1 行(目安 50 字)。color 省略時は左黒・右キャメル。

## timeline — タイムライン(拡張)

横一直線 + 赤マーカーのマイルストーン表示。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` / `secnum` | ✓ | ページ見出しと番号 |
| `milestones` | ✓ | 配列(3〜6)。`{"when": "2026 Q1", "what": "できごと"}`。`what` は `\n` で改行可 |

## table — 表(拡張)

黒ヘッダー + 白/薄グレー交互行のデータ表。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` / `secnum` | ✓ | ページ見出しと番号 |
| `columns` | ✓ | 列名の配列(2〜5 列) |
| `rows` | ✓ | 行データの二次元配列(7 行まで) |

## full_image — 全面ビジュアル(拡張)

画像をスライド全面にクロップ配置。章の合間のリズム作りに。

| フィールド | 必須 | 説明 |
|---|---|---|
| `image` | ✓ | 画像ファイルパス |
| `caption` | | 左下の黒帯キャプション |

## palette — カラーパレット

ブランドカラー 7 色の紹介ページ。内容は固定。通常の資料には入れない。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` | | ヘッダー(既定のまま "Colour Palette" 推奨) |
| `secnum` | | 左上の番号 |

## closing — 結び

表紙と同デザイン。デッキの末尾に使う。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` | ✓ | 例 "Thank You!" |

## 備考

- フッター("January 26" / "© Marni 2026, All rights reserved")と
  ページ番号はスライドマスター由来で全スライドに自動で付く。
- スライドサイズは 10 × 5.63 インチ(16:9)。
- 同じタイプを何度でも使える(本文ページを 5 枚並べる等)。
