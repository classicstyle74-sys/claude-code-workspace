# スライドタイプ仕様

`build_deck.py` に渡すスペック JSON の形式:

```json
{
  "slides": [
    { "type": "<タイプ名>", ...フィールド... }
  ]
}
```

全タイプ共通の任意フィールド:

- `notes` — スピーカーノート(文字列)

テキスト系フィールドは `\n` で段落を分けられる。`null` または省略で
テンプレートの元テキストが残るため、**表示されるフィールドは必ず指定する**こと
(プレースホルダー文言が残ってしまう)。

文字数の「目安」は半角換算。全角文字は約2倍の幅を取るため、日本語では
目安の半分程度と考える。

---

## cover — 表紙

赤背景 + MARNI ロゴ。デッキの先頭に使う。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` | ✓ | 表紙タイトル(中央下部、目安 60 字) |

## toc — 目次

グレー背景。番号 / 項目名 / ページ番号の 3 列。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` | | ヘッダー(既定 "Table of Content") |
| `secnum` | | 左上の番号(既定 "0.0") |
| `items` | ✓ | 配列。各要素 `{"num": "1.0", "title": "...", "page": "04"}` |

最大 9 行。`title` は 1 行に収まるように(目安 45 字)。

## section_red — セクション区切り(赤)

赤一色 + 左上に「番号 + セクション名」。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` | ✓ | セクション名(目安 50 字) |
| `secnum` | ✓ | セクション番号(例 "1.0") |

## section_black — セクション区切り(黒)

黒一色 + キャメル色の見出し。フィールドは section_red と同じ。

## text_image — 本文 + 画像

グレー背景。左 1/3 に本文、右 2/3 に画像パネル。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` | ✓ | ページ見出し(目安 50 字) |
| `secnum` | ✓ | 左上の番号(例 "2.1") |
| `body` | ✓ | 本文(目安 700 字 / 日本語 350 字) |
| `image` | | 画像ファイルパス。省略時はその領域は空白(背景色)になる |

画像なしの純テキストページとしても使える。

## two_images — 画像 2 枚

グレー背景。大きな画像パネル 2 枚 + 下部キャプション。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` | ✓ | ページ見出し |
| `secnum` | ✓ | 左上の番号 |
| `images` | | パスの配列(最大 2)。`[左, 右]` |
| `caption` | | 中央下のキャプション(目安 40 字) |

## three_columns — 3 カラム比較

黒い帯(全体見出し + 列見出し 3 つ)+ 画像 3 枚 + 説明文 3 つ。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` | ✓ | ページ見出し |
| `secnum` | ✓ | 左上の番号 |
| `band_title` | ✓ | 黒帯上部の全体見出し(目安 60 字) |
| `columns` | ✓ | 配列(最大 3)。各要素 `{"subtitle": "...", "image": "パス", "body": "..."}` |

`body` は短く(目安 120 字 / 日本語 60 字)。列が 2 つの場合、3 列目の
`subtitle`/`body` に `""` を指定してプレースホルダー文言を消すこと。

## quote — 引用・キーメッセージ

黒背景 + キャメル色の大きな引用文。

| フィールド | 必須 | 説明 |
|---|---|---|
| `quote` | ✓ | 引用文(目安 220 字 / 日本語 110 字)。引用符も含めて書く |
| `label` | | 上部の小さなラベル(発言者など)。省略時は空になる |

## palette — カラーパレット

ブランドカラー 7 色の紹介ページ。内容は固定。通常の資料には入れない。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` | | ヘッダー(既定のまま "Colour Palette" 推奨) |
| `secnum` | | 左上の番号 |

## closing — 結び

表紙と同デザイン。デッキの末尾に使う。

| フィールド | 必須 | 説明 |
|---|---|---|
| `title` | ✓ | 例 "Thank You!" |

## 備考

- フッター("January 26" / "© Marni 2026, All rights reserved")と
  ページ番号はスライドマスター由来で全スライドに自動で付く。
- スライドサイズは 10 × 5.63 インチ(16:9)。
- 同じタイプを何度でも使える(本文ページを 5 枚並べる等)。
