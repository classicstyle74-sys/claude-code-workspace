# よくあるエラーと対処法

コード納品時、「よくあるエラーと対処法」セクションには、生成したコードに関係する項目を
この一覧から抜粋して記載する。

## VBA実行時エラー

| エラー | 主な原因 | 対処法 |
|---|---|---|
| 実行時エラー 9「インデックスが有効範囲にありません」 | 指定したシート名がブックに存在しない（前後の空白・全角半角違いを含む） | シート見出しの名前を正確にコピーして入力する。空白が入っていないか確認する |
| 実行時エラー 1004「アプリケーション定義またはオブジェクト定義のエラー」 | セル範囲の指定ミス（例: `A1:C` のような不正な範囲）、保護されたシートへの書き込み | 範囲指定を `A1:C10` の形式に直す。シート保護のパスワードが正しいか確認する |
| 実行時エラー 1004「'xxx.xlsx' が見つかりません」 | ファイルが移動・削除された、拡張子の指定違い（xls / xlsx / xlsm） | フォルダ内の実際の拡張子を確認し、コード先頭の `TARGET_EXT` を合わせる |
| 実行時エラー 53「ファイルが見つかりません」 | `Name` や `FileCopy` の対象ファイルが存在しない、パスの区切り誤り | ログに記録されたファイル名を確認する。ネットワークドライブの接続を確認する |
| 実行時エラー 55「ファイルは既に開かれています」 | 対象ファイルを自分または他の人がExcelで開いたまま実行した | 対象ファイルをすべて閉じてから実行する。共有フォルダの場合は他の利用者にも確認する |
| 実行時エラー 58「既に同名のファイルが存在しています」 | リネーム先と同じ名前のファイルが既にある（対応表の新名が重複） | 対応表のB列に重複が無いか確認する。テンプレートは重複時スキップしてログに残す |
| 実行時エラー 70「書き込みできません」 | ファイルが読み取り専用、フォルダへの書き込み権限が無い | ファイルのプロパティで読み取り専用を解除する。権限のあるフォルダにコピーして実行する |
| 実行時エラー 75「パス名が無効です」 | フォルダ名に使えない文字、パスが長すぎる（260文字超） | フォルダを浅い階層（例: `C:\work`）に移して実行する |
| 実行時エラー 76「パスが見つかりません」 | ネットワークドライブ切断、フォルダ名変更 | エクスプローラーでフォルダを開けるか確認してから再実行する |
| 実行時エラー 424「オブジェクトが必要です」 | modCommon.bas を追加し忘れている、変数のSet忘れ | modCommon.bas が同じブックの標準モジュールに追加されているか確認する |
| 「PasteSpecialメソッドは失敗しました」 | コピー元とコピー先で結合セルの形が異なる、コピー状態が解除された | 範囲内の結合セルをそろえる。範囲を結合セルを含まない形に分けて実行する |

## シート保護まわり

| 症状 | 原因 | 対処法 |
|---|---|---|
| 「シートの保護を解除するには…」ダイアログが出る／1004エラー | 保護パスワードの指定漏れ・誤り | コード先頭の `SHEET_PASSWORD` に正しいパスワードを設定する |
| 処理後にシートが保護されていない | エラーで再保護前に中断した | ログでエラー原因を解消して再実行するか、手動で再保護する。バックアップから戻すのも可 |
| ブック保護（構成の保護）で失敗する | シート保護とは別に「ブックの保護」が掛かっている | `wb.Unprotect Password:=...` / `wb.Protect Password:=...` の処理を追加する |

## マクロ実行前の問題

| 症状 | 原因 | 対処法 |
|---|---|---|
| マクロのボタンや実行メニューが出ない | ファイルが .xlsx（マクロ保存不可）になっている | マクロを入れるブックは「マクロ有効ブック（.xlsm）」で保存する |
| 「マクロが無効にされました」の警告 | セキュリティ設定でマクロがブロックされている | ファイルを右クリック→プロパティ→「許可する」にチェック。または「信頼できる場所」にフォルダを登録する |
| コンパイルエラー「変数が定義されていません」 | `Option Explicit` 環境で変数宣言漏れ（カスタマイズ時に多い） | エラー箇所の変数を `Dim 変数名 As 型` で宣言する |
| コンパイルエラー「SubまたはFunctionが定義されていません」 | modCommon.bas の追加忘れ、関数名の書き換えミス | modCommon.bas をインポートする。関数名のスペルを確認する |

## 環境による問題

| 症状 | 原因 | 対処法 |
|---|---|---|
| OneDrive/SharePoint上のフォルダで失敗する | パスが `https://` 形式になる、同期のタイミングでロックされる | ローカルにコピーして処理し、終わってから戻す。または「常にこのデバイス上に保持する」を設定する |
| 処理が途中で極端に遅くなる | ScreenUpdating/Calculation が戻っていない、大量ファイル | テンプレートの Cleanup 処理が実行されているか確認する。件数が多い場合は分割して実行する |
| 日本語ファイル名が文字化けする（PowerShell） | CSVの文字コード不一致 | 対応表CSVを「CSV UTF-8」または Shift-JIS で保存し直す。`-Encoding` 指定を合わせる |
| PowerShellスクリプトが実行できない | 実行ポリシーの制限 | PowerShellで `Set-ExecutionPolicy -Scope Process RemoteSigned` を実行してから起動する |

## トラブル時の復旧手順

1. 処理を中断した場合も、元ファイルは対象フォルダ内の `backup_日付_時刻` フォルダに残っている
2. `エラーログ_日付_時刻.txt` を開き、失敗したファイルと原因を確認する
3. 原因を解消（ファイルを閉じる、パスワード設定など）してから再実行する
4. 再実行すると新しいバックアップフォルダが作られるため、不要になった古いバックアップは手動で削除してよい
