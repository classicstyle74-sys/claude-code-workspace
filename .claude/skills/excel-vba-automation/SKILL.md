# Excel VBA Automation Skill

Excel・VBA・PowerShellによる業務自動化コードを、**コピペで動く完成版**として生成するためのスキル。
断片コードは出さない。必ず「そのまま標準モジュールに貼れば動く」状態で納品する。

## 対象業務

| 業務 | 使用テンプレート |
|---|---|
| 任意フォルダ内のExcelファイル一括処理 | `templates/Template_ExcelBatch.bas` |
| 任意フォルダ内のPDFファイル名変更（対応表方式） | `templates/Template_FileRename.bas` |
| ひな型Excelから書式コピー | `templates/Template_CopyFromTemplate.bas` |
| ひな型Excelから関数（数式）コピー | `templates/Template_CopyFromTemplate.bas` |
| 任意セル・任意シートの一括変更 | `templates/Template_ExcelBatch.bas` |
| ファイル一覧出力 | `templates/Template_FileList.bas` |
| VLOOKUPのような対応表を使ったファイル名変換 | `templates/Template_FileRename.bas` |
| シート保護されたExcelへの対応 | `templates/modCommon.bas`（全テンプレート共通） |
| VBAが使えない環境でのファイル操作 | `templates/Rename-WithMapping.ps1`（PowerShell代替） |

すべてのテンプレートは共通モジュール `templates/modCommon.bas` を前提とする。
**コードを生成するときは、まず該当テンプレートと modCommon.bas を読み、それをベースにカスタマイズすること。**

## 作業手順

### 1. 要件ヒアリング（不明点があれば必ず確認する）

コード生成前に以下を確認する。ユーザーがすでに指定している項目は聞き直さない。

- [ ] 対象フォルダの決め方 → **原則、実行のたびにダイアログで選択させる**（固定パスにしない）
- [ ] 対象ファイルの拡張子（xlsx / xlsm / xls / pdf / csv など）→ 明確に1つ以上指定
- [ ] ひな型ファイルが必要か → 必要なら**実行時にファイル選択ダイアログで選ばせる**
- [ ] 対象シート名 → 実行時にInputBoxで確認、またはユーザー指定の固定名
- [ ] 対象セル・範囲（例: `B2`, `A1:C10`）→ 実行時にInputBoxで確認、またはユーザー指定
- [ ] シート保護の有無とパスワード → 保護がある場合は解除→処理→**再保護**
- [ ] 書き込む値・処理内容の詳細

### 2. テンプレート選択とカスタマイズ

1. 上の表から該当テンプレートを選び、`templates/` から読み込む
2. `'▼▼▼ カスタマイズ箇所 ▼▼▼` ブロックの定数をユーザー要件に合わせて書き換える
3. 処理本体（`ProcessOneFile` 等）をユーザーの業務内容に合わせて実装する
4. modCommon.bas はそのまま使う（必要な関数だけ抜き出して1モジュールにまとめてもよい）

### 3. 品質チェック（納品前に必ず全項目を確認）

- [ ] `Option Explicit` がモジュール先頭にある
- [ ] すべての変数が `Dim` で宣言されている
- [ ] エラー処理（`On Error`）が入っており、**1ファイルのエラーで全体が止まらない**
- [ ] `Workbooks.Open` したブックは、正常時もエラー時も**必ず `Close` される**
- [ ] `Application.ScreenUpdating` / `DisplayAlerts` を変更した場合、
      **終了処理（エラー時含む）で必ず元に戻している**（`Finally` 相当のラベルで戻す）
- [ ] 元ファイルを変更する処理では、処理前に**バックアップフォルダへコピー**している
- [ ] エラーファイルはログ（テキストファイル）に記録される
- [ ] 処理完了後に**成功件数・失敗件数**をMsgBoxで表示する
- [ ] シート保護を解除した場合、処理後に再保護している
- [ ] 初心者が読める日本語コメントが入っている
- [ ] 断片ではなく、Sub/Functionが閉じた完成コードになっている

### 4. 出力フォーマット（この順番・この見出しで必ず出す）

## 標準仕様（全コード共通・省略禁止）

1. **フォルダは実行のたびにユーザーに選択させる**（`modCommon.SelectFolder` を使用）
2. **対象ファイルは拡張子ごとに明確に指定する**（`Dir(folder & "\*.xlsx")` のように限定。`*.*` は使わない）
3. **ひな型ファイルが必要な場合は実行時に選択させる**（`modCommon.SelectFile` を使用）
4. **対象シート名はユーザーに確認する**（InputBoxまたは事前ヒアリングで確定）
5. **対象セル・範囲はユーザーに確認する**（同上）
6. **シート保護がある場合は解除して処理し、最後に必ず再保護する**（`UnprotectIfNeeded` / `ReprotectIfNeeded`）
7. **元ファイルは原則バックアップを作成してから処理する**（`backup_yyyymmdd_hhmmss` フォルダにコピー）
8. **エラーが起きたファイルは処理を止めず、ログに記録して次のファイルへ進む**
9. **処理完了後に成功件数・失敗件数・ログの場所を表示する**
10. **コード内にコメントを入れて、初心者でも修正できるようにする**
    （特にカスタマイズ箇所は `'▼▼▼ カスタマイズ箇所 ▼▼▼` で囲んで目立たせる）

## 品質基準（違反したコードを出さない）

- コピペで動く完成版を出す。途中の断片コードだけを出さない
- 変数宣言を必ず行い、`Option Explicit` を全モジュールに入れる
- エラー処理を必ず入れる（少なくとも「ファイル単位のスキップ＋ログ」と「全体のクリーンアップ」の2層）
- ファイルを開いたら必ず閉じる（エラー経路でも `If Not wb Is Nothing Then wb.Close False`）
- `DisplayAlerts` / `ScreenUpdating` / `Calculation` の戻し忘れを防ぐ
  （必ず `Cleanup:` ラベルを通る構造にする）
- 保存が必要な処理は `wb.Close SaveChanges:=True`、読み取りだけなら `SaveChanges:=False` を明示する

## PowerShellを使う場合

- VBAが使えない環境（Excel未インストール、マクロブロック環境）でのファイル名変更・一覧出力は
  `templates/Rename-WithMapping.ps1` をベースにPowerShellで提供する
- PowerShellでも同じ標準仕様を守る：フォルダ選択ダイアログ、拡張子限定、バックアップ、
  エラーログ、成功・失敗件数の表示、初心者向けコメント
- 実行方法として「右クリック→PowerShellで実行」と実行ポリシーの注意
  （`Set-ExecutionPolicy -Scope Process RemoteSigned` など）を必ず添える
