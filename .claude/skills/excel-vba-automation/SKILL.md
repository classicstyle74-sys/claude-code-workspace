# Excel VBA Automation Skill

## 目的

Excel、VBA、PowerShellを使った業務自動化コードを、**安定して再利用できる完成版**として生成する。
断片コードではなく、そのまま標準モジュールに貼り付けて実行できる状態で出力すること。

## 対象業務とテンプレート対応表

コード生成時は、まず該当するテンプレートを読み込み、それをベースにユーザーの要件へ合わせて調整する。
テンプレートはすべて `templates/` フォルダに同梱されている。

| 業務 | テンプレート |
|---|---|
| 任意フォルダ内のExcelファイル一括処理 | `templates/BatchProcessExcel.bas` |
| 任意フォルダ内のPDFファイル名変更 | `templates/RenamePdfFiles.bas` |
| ひな型Excelから書式コピー | `templates/CopyFormatFromTemplate.bas` |
| ひな型Excelから関数コピー | `templates/CopyFormulasFromTemplate.bas` |
| 任意セル・任意シートの一括変更 | `templates/BulkUpdateCells.bas` |
| ファイル一覧出力 | `templates/ExportFileList.bas`（PowerShell版: `templates/ExportFileList.ps1`） |
| 対応表を使ったファイル名変換（VLOOKUP方式） | `templates/RenameFilesWithMapping.bas`（PowerShell版: `templates/RenameFilesWithMapping.ps1`） |
| シート保護されたExcelへの対応 | 全テンプレートに組み込み済み（`PROTECT_PASSWORD` 定数） |

該当する業務が複数にまたがる場合は、`BatchProcessExcel.bas` を骨格にして、他テンプレートの処理部分を組み合わせる。

## 標準仕様（コード生成時に必ず守ること）

1. **フォルダは実行のたびにユーザーに選択させる**
   `Application.FileDialog(msoFileDialogFolderPicker)` を使う。パスをコードに直書きしない。
2. **対象ファイルは拡張子ごとに明確に指定する**
   `Const TARGET_EXT As String = "*.xlsx"` のように定数で宣言し、`Dir` 関数で絞り込む。
3. **ひな型ファイルが必要な場合は実行時に選択させる**
   `Application.FileDialog(msoFileDialogFilePicker)` を使い、拡張子フィルターを設定する。
4. **対象シート名はユーザーに確認する**
   `InputBox` で実行時に入力させる。既定値を入れておく。
5. **対象セルまたは範囲はユーザーに確認する**
   `InputBox` でアドレス（例: `A1` や `B2:D10`）を入力させ、`Range()` に渡す前に妥当性を確認する。
6. **シート保護がある場合は解除して処理し、最後に再保護する**
   `ws.ProtectContents` で保護状態を記録し、`Unprotect` → 処理 → 元が保護済みなら `Protect` で戻す。
   パスワードは `PROTECT_PASSWORD` 定数にまとめる。
7. **元ファイルは原則バックアップを作成してから処理する**
   処理前に `backup_yyyymmdd_hhnnss` フォルダを作り、`FileCopy` で複製する。
8. **エラーが起きたファイルは処理を止めず、ログに記録する**
   ファイル単位で `On Error Resume Next`（またはエラーハンドラ）を使い、失敗内容をログ文字列に蓄積して
   処理フォルダ内にテキストファイルとして出力する。
9. **処理完了後に成功件数・失敗件数を表示する**
   `MsgBox` で「成功 n 件 / 失敗 n 件」とログファイルの場所を表示する。
10. **コード内にコメントを入れて、初心者でも修正できるようにする**
    処理ブロックごとに日本語コメントを入れ、カスタマイズ箇所は
    `'=== ここに処理を書く（カスタマイズ箇所）===` のように明示する。

## 出力フォーマット（回答は必ずこの構成で出す）

コードを生成したら、以下の6セクションを必ずすべて含めて回答する。

1. **完成版VBAコード** — 標準モジュールにそのまま貼れる全文。断片で出さない。
2. **使い方** — VBE の開き方、標準モジュールへの貼り付け、実行手順を番号付きで。
3. **事前準備** — マクロ有効化、対象フォルダの整理、ひな型・対応表の用意など。
4. **注意点** — 上書き保存の有無、バックアップの場所、実行前に閉じるべきファイルなど。
5. **よくあるエラーと対処法** — 表形式で。最低限、以下を含める:
   - 「実行時エラー 9: インデックスが有効範囲にありません」→ シート名の誤り
   - 「実行時エラー 1004」→ 保護の解除失敗、範囲指定の誤り
   - 「実行時エラー 70: 書き込みできません」→ ファイルが開かれている／読み取り専用
   - 「実行時エラー 53: ファイルが見つかりません」→ パス・拡張子の誤り
   - 「マクロが無効になっています」→ セキュリティ設定・ブロック解除
6. **カスタマイズ箇所** — 変更してよい定数・処理ブロックを、行の目印（コメント）とともに列挙する。

## 品質基準（生成コードのチェックリスト）

出力前に以下をすべて満たしているか確認すること。

- [ ] コピペで動く完成版である（断片コードだけを出していない）
- [ ] モジュール先頭に `Option Explicit` がある
- [ ] すべての変数を `Dim` で宣言している
- [ ] エラー処理（`On Error`）が入っており、1ファイルの失敗で全体が止まらない
- [ ] `Workbooks.Open` したブックは、成功・失敗どちらの経路でも必ず `Close` している
- [ ] `Application.ScreenUpdating` / `DisplayAlerts` を変更した場合、終了処理（Cleanupラベル等）で**必ず元に戻している**
- [ ] シート保護の解除／再保護が対になっている
- [ ] バックアップ作成が処理より先に行われている
- [ ] 成功・失敗件数の表示とログ出力がある
- [ ] 日本語コメントで各ブロックの意図が説明されている

## PowerShellを使う場合の指針

- **Excelのセル・書式・関数を扱う処理** → VBAを第一候補にする（COM操作より安全で配布も容易）。
- **ファイル名変更・一覧出力などExcelを開く必要がない処理** → PowerShell版も提示できる
  （`templates/ExportFileList.ps1`, `templates/RenameFilesWithMapping.ps1`）。
- PowerShell版でも標準仕様は同じ: フォルダ選択ダイアログ、バックアップ、エラーログ、件数表示を必ず入れる。
- 実行方法として「右クリック → PowerShellで実行」ができない環境向けに、
  `powershell -ExecutionPolicy Bypass -File スクリプト名.ps1` の起動例を必ず添える。

## 生成時の進め方

1. ユーザーの依頼を上の対応表に当てはめ、該当テンプレートを読む。
2. テンプレートの定数（拡張子・パスワード・バックアップ有無）と処理ブロックを要件に合わせて修正する。
3. 標準仕様1〜10と品質基準チェックリストを満たしているか確認する。
4. 出力フォーマットの6セクション構成で回答する。
5. 要件が曖昧な場合（対象拡張子、シート名の扱い、上書きか別名保存かなど）は、
   勝手に決めずにユーザーへ確認する。ただし確認項目は最小限に絞る。
