# Retail Business Review Skill

ラグジュアリーブランドの日本リテール事業における売上レビューを、一貫した構成・トーンで作成するためのスキル。店長会資料、社内報告、HQ(本社)向け英語サマリーまで、同じデータセットから一気通貫でアウトプットする。

## 対象業務

- 店舗別売上レビュー
- 期間レビュー(1-6月、1-12月など月次/四半期/半期)
- ハイスペンダー分析
- 顧客ステータス別分析(New / Loyal / Lost / High / Top)
- KPI分解(TR / UPT / ATV / AP / Quantity / Revenue)
- 外商ビジネス強化の示唆
- DSR(Daily Sales Report)に基づく店舗アクション設計

## 進め方

### ステップ1: 入力データの確認

分析を始める前に、以下が揃っているか確認する。欠けているものは省略せず、後述の「不足データ」として明記した上で分析を進める。

- 売上データ(Excel/CSV): 店舗別・期間別のRevenue, Quantity, TR(Transaction数)
- 店舗別KPI: TR, UPT(Unit Per Transaction), ATV(Average Transaction Value), AP(Average Price)
- 顧客ステータス別データ: New / Loyal / Lost / High / Top顧客の人数・売上
- 前年同期実績(YoY比較用)
- Budget(予算)実績
- 店舗コメント・ミーティングメモ(定性情報)

データが不足している場合は仮定を置かず、"不足データ: ○○" と明記し、影響範囲(例: 「外商示唆はデータ不足のため参考情報にとどまる」)を一言添える。

### ステップ2: KPI分解のロジック

Revenueの増減は必ず以下の式で分解して要因を特定する。単一指標(Revenueのみ)での評価はしない。

```
Revenue = TR × ATV
ATV     = UPT × AP
Revenue = TR × UPT × AP
```

- **TR(客数)の増減** → 集客・来店動機の問題か
- **UPT(客単価内の点数)の増減** → 提案力・複数点購買の問題か
- **AP(客単価内の単価)の増減** → 客層・アイテムミックスの問題か

前年差(YoY)とBudget差は必ず分けて見る。どちらか一方だけを見て「好調/不調」と判断しない。
(例: 「YoYは+8%だがBudget比は-5%」→ 昨年が弱かっただけで、目標未達という評価が正しい)

### ステップ3: 顧客ステータス分析

New / Loyal / Lost を必ず分けて分析する。まとめて「顧客数」としない。

- **New顧客**: 新規獲得数、新規売上比率、新規からのハイスペンダー転換有無
- **Loyal顧客**: リピート率、来店頻度、Loyal層の売上構成比の推移
- **Lost顧客**: 離反数、離反した顧客のステータス(旧High/Top含むか)、離反理由の仮説(店舗コメントから)

### ステップ4: ハイスペンダー分析

ハイスペンダーは **人数** と **金額** の両方を必ず見る。金額シェアだけで語らない。

- ハイスペンダー人数の増減(新規流入 vs 離反)
- ハイスペンダーの売上シェア(集中度リスクの確認)
- High → Top への昇格数、Top → Highへの降格数
- 外商対応が必要な顧客の有無(店舗コメント・ミーティングメモから抽出)

### ステップ5: 外商・百貨店連携の示唆

外商データが十分にある場合のみ具体的な示唆を出す。データが不十分な場合は「不足データ」と明記し、一般的な着眼点(例: 「ハイスペンダー上位◯名の外商担当有無を確認」)にとどめる。

### ステップ6: 店舗別アクションプラン

- 結果の説明で終わらせず、必ず「次に何をするか」まで落とす
- アクションは店長がそのまま実行できる粒度にする(抽象的な「接客強化」ではなく、「UPT改善のため、来店客への2点提案トークを◯月◯日までに全スタッフに徹底」など)
- 1店舗につき、課題→要因→アクションの3点セットで記載する

## 出力構成

以下の9セクションを、この順番で出力する。ユーザーが一部のみ求めている場合は該当セクションのみでよい。

1. **Executive Summary** — 全体の結果を3〜5行で要約(Revenue、YoY、Budget比、主要因)
2. **全体結果レビュー** — 全社/全店の実績サマリー、TR/ATV/UPT/APの分解表
3. **店舗別の強み・課題** — 店舗ごとの良かった点・課題を箇条書き
4. **KPI分解** — TR / UPT / ATV / AP / Quantity / Revenueの詳細テーブルと要因分析
5. **ハイスペンダー分析** — 人数・金額の両面、昇格/降格、New/Loyal/Lostとの関連
6. **外商・百貨店連携の示唆** — 外商強化ポイント、データ不足の場合は明記
7. **店舗別アクションプラン** — 店舗別に課題→要因→アクション
8. **店長会向けスライド骨子** — 1スライド1メッセージのタイトル+要点リスト形式(`templates/slide_outline_template.md`参照)
9. **HQ向け英語サマリー** — 定量根拠を明確にした簡潔な英語サマリー(`templates/hq_summary_template.md`参照)

具体的なフォーマットは `templates/` 内のテンプレートを参照すること。出力例は `examples/example_output_ja.md` を参照。

## 分析ルール(必須)

- Revenueだけで判断せず、TR・ATV・UPT・AP・Quantityに分解して要因を語る
- 前年差(YoY)とBudget差は分けて記載する。両方が同じ方向とは限らない
- New顧客・Loyal顧客・Lost顧客は必ず分けて見る。合算しない
- ハイスペンダーは人数と金額の両方を見る。片方だけで「増えた/減った」と言わない
- 結果の記述だけで終わらせず、必ず次のアクションに落とす
- コメントは抽象論を避け、店舗が具体的に実行できる行動(担当・期限のイメージが持てる粒度)にする
- 不明点・データ不足は推測で埋めず、「不足データ」として明記する

## 出力トーン

- 日本語は簡潔・常体ベース(「〜だ」「〜である」)、ビジネス文書として通用する表現
- 箇条書き中心。長い説明文は避ける
- 店長会向けスライド骨子は1スライド1メッセージ厳守
- HQ向けは英語、定量根拠(数値・%)を必ず明記
- ラグジュアリーブランドのリテール文脈(接客品質・顧客関係・ブランド体験)を前提にした表現を使う

## 補助スクリプト

`scripts/kpi_breakdown.py` は、店舗別のRevenue/TR/Quantityから UPT・ATV・AP を計算し、前年・Budget比較テーブルを生成する補助スクリプト。Excel/CSVの生データを受け取り、KPI分解セクション・全体結果レビューセクション用の集計テーブルを作る際に使用する(必須ではなく、集計作業を効率化するための補助)。

```
python scripts/kpi_breakdown.py --input sales_data.csv --output kpi_summary.csv
```
